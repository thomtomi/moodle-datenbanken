# Projekteinstieg für Agents

Lesen Sie vor der ersten Projektarbeit die zentralen Regeln in [00-setup/agent_instruction.md](00-setup/agent_instruction.md) vollständig und wenden Sie sie auf den Auftrag an. Lesen Sie die Datei nach einer Änderung erneut.

Diese Datei dient nur als Einstieg. Fachliche Regeln und Workflow werden ausschliesslich in der zentralen Datei gepflegt. Falls sie nicht lesbar ist, melden Sie den konkreten Fehler; behaupten Sie nicht, die Regeln geladen zu haben.
