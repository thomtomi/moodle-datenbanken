# Projektablauf

- Lesen Sie vor der ersten inhaltlichen Antwort oder Änderung `00-setup/agent_instruction.md` vollständig. Diese Datei ist die fachliche und prozessuale Quelle der Wahrheit.
- Erfassen Sie vor Änderungen mit `git status --short` den Bestand. Erhalten Sie fremde Änderungen sowie alle Originale unter `02-rohdaten/` unverändert.
- Klären Sie fehlende Angaben nur, wenn sie Lernziel, Datenmodell, Berechtigungen, Datenverlust oder das Ausgabeformat wesentlich beeinflussen. Treffen Sie sonst eine sichtbare, reversible Annahme.
- Nutzen Sie im Plan-Modus nur Lesezugriffe. Führen Sie im Agent-Modus nach einem konkreten Umsetzungsauftrag kleine, zusammenhängende Änderungen aus; Continue soll jeden Werkzeugzugriff zur Bestätigung vorlegen.
- Prüfen Sie nach jeder Änderung die betroffenen lokalen Artefakte mit dem vorhandenen, engsten Prüfwerkzeug. Melden Sie nur tatsächlich ausgeführte Prüfungen und Ergebnisse.
- Ändern oder veröffentlichen Sie keine produktiven Moodle-Aktivitäten. Ein lokaler Auftrag autorisiert weder Import noch Veröffentlichung.
- Antworten, Dokumentation und sichtbare Texte sind auf Deutsch in der Sie-Form und mit Schweizer Rechtschreibung zu verfassen.
